The rules

  • The Map chat may restart the editor when its run needs it (the owner, 2026-10-21, "Map chat can restart when needed"): it tells the Master chat "restart needed" with L_Main saved and the builder stopped, the Master chat confirms the editor is free, it runs the restart script without a build, and starts the builder again.
  • Anything that interrupts another chat (closing or restarting the editor, an editor build, a background editor, Live Coding on shared modules, git on the shared tree) is asked for at the Master chat first.
  • Every chat answers "saved, go ahead" or "finish this first, about N minutes"; the go comes only once all have saved. The Master's go is the owner's permission ("when you hear the editor is not in use and everything is saved then you can give the go ahead to each one").
  • When the usage cap hits, everyone holds until the daily reset at 2 AM.
  • The Map chat's work has priority in the editor. A gap from its run is taken at a tile or volume boundary, never by closing the editor mid-step: the Master creates the file D:\Tharrn\Saved\Terrain\main\PAUSE; the builder finishes the piece in hand, saves L_Main, logs "paused" in D:\Tharrn\Saved\ClaudeScratch\map_all.log and waits; deleting the file lets it carry on, reconnecting if the editor was restarted.
  • Each chat sends the Master a one-line status when a step worth the owner's eye finishes; it lands here.
