Development

How Tharrn is made, where it stands, and what is still open.

How Tharrn is built

  • One module at a time, in the live Unreal Editor through Unreal MCP. Each module is polished and passes every check before the next starts, and the owner's play-test closes it when there is something to play.
  • Online from the first system. Every feature is tested with a server and two clients, with simulated lag and packet loss, and with a player joining late.
  • C++ for complex systems, Blueprints for simple ones, and both carry notes you can read when you open them: comment boxes in Blueprints, a description on every variable.
  • Game data lives in CSV and JSON files (D:\Tharrn\Data) and is imported into Unreal's data tables; the files are the source.

What P1 built

  • In the build Data: weapons, creatures and zones import into Unreal's data tables and are read back and compared, with no problems.
  • In the build Tests: 31 automated tests pass.
  • In the build Multiplayer test: a server with two clients, as a host who plays and as a server with no player, with 50 ms of lag each way and 1 % packet loss; a third player joins halfway and gets the current state. Round trips 119–172 ms.
  • In the build Test range: a grey map with targets at 10, 25, 50 and 100 m and a network probe that shows what each player receives.

What P2 built

  • In the build The player: the Game Animation Sample's motion-matched character, with its camera, mantle and vault, made ready for online play: sprinting, walking, strafing and aiming travel with every movement update, so the server agrees with the player at all times.
  • In the build Slide: sprint and press crouch; about 1 second and 5 metres on flat ground, faster downhill, ending in a crouch.
  • In the build Mantle and vault, checked by the server: the server looks for the ledge itself and refuses a climb where there is none, so a cheating client cannot climb thin air.
  • In the build Aim: the camera comes in over the shoulder.
  • In the build Checked online with 50 ms of lag each way and 1 % packet loss: every player's scripted run, slide and climbs match on every machine to the centimetre.

Play-test P2 (about 10 minutes)

  1. Open Tharrn; the editor opens the test range. Press Play.
  2. The sign on the left lists the keys. Run with W A S D, hold Shift to sprint, Ctrl to walk, C to crouch. Sprint and press C to slide; C again stands up.
  3. Run at the three blocks on the left and press Space in front of each: a hurdle (1 m), a mantle (1.5 m), a climb (2.5 m).
  4. Hold the right mouse button to aim. The middle mouse button switches between facing the camera and turning towards where you run.
  5. Three dots next to Play: Number of Players 2, Net Mode "Play As Listen Server"; Play. Move in one window and watch the other.
  6. Set it back to 1 player and "Play Standalone", then tell Claude what feels wrong or good.
